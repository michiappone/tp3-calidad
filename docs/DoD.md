# Definition of Done
- El código debe superar la verificación sintáctica y ejecutarse sin errores críticos.
- El 100 % de las pruebas asociadas debe aprobarse.
- El código nuevo debe alcanzar al menos el 80 % de cobertura. En este proyecto se mide también cobertura de ramas.
- Otro integrante debe revisar el PR y sus observaciones deben resolverse.
- Formatter y linter deben aprobarse.
- La documentación debe reflejar los cambios.

Etiquetas propuestas: bug (fallos), technical-debt (mantenibilidad), documentation (documentación), feature (funcionalidades).
